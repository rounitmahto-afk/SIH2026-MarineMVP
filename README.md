# SIH 2026 Marine Sonar MVP

Production-oriented MVP for:

Real side-scan sonar
-> real object detection
-> acoustic evidence
-> cross-frame persistence
-> geolocation when metadata exists
-> human review
-> reports

NON-NEGOTIABLE:
- No mock detections.
- No fake coordinates.
- No hardcoded result arrays.
- No fake metrics.
- Database is authoritative.
- Missing metadata remains unavailable.
- Real source data and model provenance are recorded.
